About CloudKeep

CloudKeep is a self-hosted private cloud for browser-based virtual desktops. It turns a single KVM host into a small fleet you can build, manage, and connect to entirely in the browser — no client to install.

How it works

A public edge (NGINX over a WireGuard tunnel) fronts a control plane running on the KVM host. When you build a machine, the host clones a pre-built golden image into an isolated, internet-only network and boots it in seconds. A secure, single-use WebSocket bridge then streams the desktop to your browser.

How to use it

Sign in at the launch portal and click + build, then choose cores, memory, and disk within your quota. When the machine reports ready, hit Connect for a full desktop. Stop, start, or delete machines any time from the dashboard.

Security

Every machine is network-isolated from the host and your LAN; access is authenticated, rate-limited, and quota-bound; and each desktop connection uses a single-use, short-lived token.
